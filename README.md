# 🌐 Personal Portfolio Website

This is my **personal portfolio website** created during my **1st Year in College**.

It is built using **HTML and CSS** and highlights key details about myself, including my **background, education, skills, hobbies, and interests**.  

This project was one of my early steps into **web development** and learning how to design structured, styled web pages.  

---

## ✨ Features
- 👤 **About Me** – A brief introduction and personal background.  
- 🎓 **Education** – Academic background and milestones.  
- 🛠️ **Skills** – Personal skills section.  
- 🎨 **Hobbies** – Personal interests and activities outside academics.  
- 💡 **Interests** – Areas of curiosity and passion.  

---

## 🛠️ Tech Stack
- **HTML5** – Page structure and content.  
- **CSS3** – Styling, layout, and simple responsive design.  

---

## 🚀 How to Run
1. Clone the repository:  
```bash
   git clone https://github.com/earlfranciss/Portfolio-Old.git
````

2. Open `index.html` in your preferred web browser.
